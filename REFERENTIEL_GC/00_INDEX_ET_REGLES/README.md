# Index du référentiel

- `CATALOGUE_RESSOURCES.csv` : inventaire des ressources confirmées (24 entrées au 2026-11-08, séparateur `;`, UTF-8).
- `SOURCES_A_VERIFIER.md` : pistes non encore vérifiées.
- `DEMANDES_A_L_EQUIPE.md` : documents à demander aux membres de l'équipe.
- `INVENTAIRE_ARBORESCENCE.md` : fonction de chaque dossier, couverture et lacunes.
- `PLAN_DE_RECHERCHE.md` : recherches prioritaires à mener.
- `JOURNAL_DES_SESSIONS.md` : compte rendu de chaque session de l'agent.

Fiches ressources : dans le sous-dossier `_FICHES/` du dossier de classement, nommées `GC-XXXX_Titre.md`.

Ne jamais confondre une piste de recherche avec une référence validée.
