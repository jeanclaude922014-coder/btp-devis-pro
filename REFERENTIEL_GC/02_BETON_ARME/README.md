# 02_BETON_ARME

Béton armé selon l'EC2 (NF EN 1992-1-1 et son annexe nationale) et le BAEL 91 révisé 99 : commentaires, exemples résolus de flexion, effort tranchant, poinçonnement, poteaux et fondations. Les textes normatifs eux-mêmes sont référencés dans 06.
