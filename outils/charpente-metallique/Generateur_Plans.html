Import depuis le classeur Excel

Dans Excel (feuille ACCUEIL), copier la cellule « CODE PLANS » puis la coller ici : les plans reprennent exactement le paramétrage du classeur.

Bouton « Enregistrer en PDF » : choisir l'imprimante « Enregistrer au format PDF » (ou « Microsoft Print to PDF »), format A4 paysage, marges par défaut, sans en-têtes ni pieds de page.
